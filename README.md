## File Naming Convention

Solution files follow a consistent naming convention:

```text
<ProblemNumber>_<ProblemName>.<extension>
```

**Examples:**

- `1_Two-Sum.java`
- `125_Valid-Palindrome.py`
- `1661_Average-Time-of-Process-per-Machine.sql`
- `1114_Print-in-Order.java`
- `2620_Counter.js`
- `183_Customers-Who-Never-Order.py`
- `192_Word-Frequency.sh`

The problem number and name make it easier to identify solutions and locate the corresponding problem on LeetCode.

## Adding New Solutions

New solutions are added manually as problems are solved.

To add a solution:

1. Solve a problem on LeetCode.
2. Save the solution in the appropriate category directory.
3. Follow the existing file naming convention.
4. Review the solution and its correctness.
5. Commit and push the changes to GitHub.

If a new programming language or problem category is introduced, create a dedicated directory when appropriate and update this README.
