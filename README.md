## File Naming Convention

Solution files follow a consistent naming convention:

```text
<ProblemNumber>_<ProblemName>.<extension>
```

Examples:

* `1_Two-Sum.java`
* `125_Valid-Palindrome.py`
* `1661_Average-Time-of-Process-per-Machine.sql`
* `192_Word-Frequency.sh`

The problem number and name make it easier to identify solutions and locate the corresponding problem on LeetCode.
